# AniClash

Это сайт, который позволит любителям аниме-контента просматривать определенные произведения совместно в режиме реального времени, также планируется геймификация просмотра путём добавления квизов прямиком в процесс просмотра, основываясь на контексте происходящего в аниме.
Решение о разработке было принято в связи с отсутствием подобных универсальных решений на рынке веб сервисов.
Проект мотивирован добровольными намерениями разработчика и желанием развивать свои навыки, параллельно разрабатывая интересный и востребованный информационный продукт. 
## Разделы
- ПРОСМОТР - вкладка для просмотра аниме
- КОМНАТЫ - вкладка для создания отдельных комнат для проведения аниме-квизов
- ПРОФИЛЬ - вкладка для отслеживания статистики

## Стек разработки
- Backend - Python, FastAPI
- Frontend - HTML, CSS, JavaScript, React
- DataBase - PostgreSQL
